# KANA NOTES — WhatsApp Report Notes (review draft)

This archive contains 30 individual UTF-8 .txt templates, READ_ALL_30.md for reading them together, INDEX.md for display names, and report_notes.json for a future importer.

These are reports of suspected harmful conduct, not legal findings. Some categories concern platform abuse and may not be crimes. No legal or current mailbox-availability claims are made. This is a content pack, not a bot update; the existing bot does not automatically import it yet.

## Edit and import

- Each display_name is the proposed name shown in the menu and subject. Numbered filenames remain stable.
- Replace {{placeholders}} with actual incident details. Never infer missing facts from a selected category, manufacture a quote, imply evidence is attached when it is not, or mark someone guilty merely because a template was chosen.
- If evidence is unavailable, say exactly that and explain what was actually observed. No template can make an unsupported allegation factual.
- The required_placeholders list describes every value an importer must resolve; it is a schema proposal, not an implemented validation feature in the current bot.
- Editing a .txt file does not automatically update JSON or READ_ALL_30.md. Treat the .txt files as review copies; sync approved changes into body_template/subject_template before future import.
- For multiple relevant categories, prepare one case-specific complaint, remove duplicated paragraphs and ensure each allegation has its own factual basis. Do not send one separate complaint per selected label.
- Before any real submission, review the rendered subject, recipient, description and attachments. Keep tests, including multiple sender tests, directed only to an inbox you control. These templates do not authorize bulk or duplicate submissions.

## Sensitive cases

Do not place real account numbers, private chat screenshots, passwords or tokens in a public repository. Do not attach child sexual exploitation material, nonconsensual intimate imagery, malicious executables or stolen data. Describe the concern without graphic detail and use appropriate platform/dedicated reporting channels. An immediate threat needs appropriate emergency help rather than reliance on an email template.

No report was submitted and no email sent while producing this archive.
